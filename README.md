# Glassmorphism Web Calculator 🧮

A modern, highly premium web calculator built with vanilla HTML, CSS, and JavaScript. Featuring a deep midnight blue dark theme, a dynamic aurora gradient background, SVG noise textures for depth, and elegant frosted glass effects.

## Features ✨
- **Premium UI:** Apple/Vercel-inspired frosted glass aesthetic.
- **Dynamic Background:** Animated radial aurora effects over a professional SVG noise texture layer.
- **Responsive:** Clean, centered grid layout.
- **Full Keyboard Support:** Use your numpad or keyboard number row, `Enter` for equals, `Backspace` for delete, and `Escape` for All Clear.
- **Precision Math:** Handles standard operations and cleans up floating-point decimals natively.

## Tech Stack 🛠️
- HTML5
- CSS3 (Custom properties, Flexbox, Grid, Animations, `backdrop-filter`)
- Vanilla JavaScript (ES6+ Classes, Event Delegation)

## How to use 🚀
Simply open `index.html` in any modern web browser to interact with the calculator. No build tools or dev server required!
